T3 immutable experiment data archive

This folder stores original bytes of recoverable Actions artifacts and the published Zenodo record 24174965 in the SAME ALRIER/T3 repository. Stage folders are montecarlo, discovery, heldout, stress, realworld, provenance, and misc. Original ZIP files are losslessly split into 32 MiB .lfs parts and accompanied by manifest.json containing original SHA-256, part hashes, source run, and artifact ID. Install Git LFS and run git lfs pull before restoring original archives with scripts/archive/restore_archive.py. The catalog/status.json file reports actual progress. A complete status covers the recorded inventory; expired/unavailable sources are explicitly reported and cannot be reconstructed solely from Actions. Publishing data to this public repository makes those data public. The workflow does not rerun experiments or invent missing results.
