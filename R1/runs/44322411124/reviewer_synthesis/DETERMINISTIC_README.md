# RQ1 deterministic control independent evidence

Original 10 x 10 Discovery training/evaluation seed candidates were recovered from the separately stored original Held Out non_evolutionary_control_scores.csv, without fitting controls or rescoring outcomes. Original four evolutionary method losses were cross-checked against the preserved R1 Held Out candidate panel. Both deterministic models used the original Discovery frozen weights.

The 288 candidate-versus-control MSE/Q95 matched contrasts use independent evaluation seeds and global Holm adjustment. Training-seed candidates are correlated within evaluation streams; these results are a posthoc reviewer sensitivity analysis, not a prospectively prespecified confirmatory family.
